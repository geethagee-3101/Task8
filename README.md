# Task 8: Sales Tracker in Google Sheets

## Objective
Build a sales tracker that automatically calculates daily, weekly, and monthly sales totals.

## Tools Used
- Microsoft Excel
- Google Sheets
- SUMIFS formulas

## Features
- Raw sales data entry
- Automatic total sales calculation
- Daily, weekly, and monthly summaries
- Data validation for quantity, price, and payment method
- Manual verification of total sales

## Files Included
- `Task8_Sales_Tracker.xlsx` – Sales tracker template
- `Task8_Sales_Tracker_Report.docx` – Task report

## Result
Added 10 sample sales records and verified the total sales amount manually.

**Verified Total Sales: ₹5,330**

## Learning Outcome
Learned how to organize sales data, use formulas, validate entries, and create automatic sales summaries.
